САЙТ СПИСАЛИ.COM — как запустить
================================

1. ФАЙЛЫ
   Маркетинговый сайт:
   index.html            — главная (лендинг) с тёмным героем и квизом по кнопке
   kak-rabotaet.html     — «Как это работает» (большая продающая статья + возражения)
   partnery.html         — страница «Партнёрам»
   blog.html             — блог
   + около 50 статей (.html) — SEO-статьи со ссылками на сервис
   politika.html         — политика конфиденциальности (152-ФЗ)

   Личный кабинет:
   kabinet-vhod.html     — страница входа (по телефону)
   kabinet.html          — ЕДИНЫЙ личный кабинет (все разделы в одном файле,
                           переключаются по левому меню без перезагрузки):
                           Обзор · Мои долги · Статус дела · Платежи и рассрочка ·
                           Документы · Чат с юристом · Калькулятор списания ·
                           Профиль · Помощь

   Прочее:
   robots.txt, sitemap.xml — для поисковиков
   img/                    — изображения (если есть)

   Логотип вшит внутрь страниц — отдельные картинки не нужны.

2. ПУБЛИКАЦИЯ
   Залейте все файлы в корень хостинга/домена spisali.com.
   Сайт статический, сборка не нужна. Вёрстка адаптивная (телефон/планшет/ПК).

3. ПРИЁМ ЗАЯВОК (важно!)
   Квиз и формы показывают экран «Заявка принята», но НИКУДА не отправляют.
   Чтобы получать заявки, в index.html найдите строку:
        var FORM_ENDPOINT='';
   и впишите адрес приёма, например Formspree:
        var FORM_ENDPOINT='https://formspree.io/f/ВАШ_КОД';
   Данные уходят POST-запросом (JSON): имя, телефон, город + ответы квиза.
   Можно подключить Telegram-бота или CRM.

4. ЛИЧНЫЙ КАБИНЕТ — рабочий ДЕМО-макет
   kabinet.html показывает, как выглядит кабинет клиента «в работе»:
   статус дела, путь по этапам, оплата/рассрочка, документы, чат, калькулятор.
   Данные — примерные. Чтобы кабинет заработал по-настоящему (реальная
   авторизация, подтягивание долгов из ФССП/БКИ/Госуслуг, онлайн-оплата,
   живой чат) — нужна серверная часть (бэкенд + интеграции + согласия 152-ФЗ).

5. ЗАМЕНИТЬ ЗАГЛУШКИ
   - телефон 8 800 000-00-00     -> ваш реальный номер (искать по файлам)
   - почта 000000@gmail.com      -> ваша реальная почта
   - фото людей (на некоторых блоках) -> реальные фото
   - домен spisali.com в sitemap/canonical -> ваш домен, если другой
   - цифры статистики и отзывы   -> ваши реальные данные

6. SEO
   У каждой страницы уникальные title/description и разметка Schema.org.
   Кабинет и политика закрыты от индексации (noindex).
   После публикации добавьте сайт в Яндекс.Вебмастер и Google Search Console,
   загрузите sitemap.xml.
